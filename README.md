## Muhammed Ali

Independent developer from Türkiye. I build tools that sit close to the machine: system daemons in Rust, local AI pipelines in Python, and game servers people actually play on.

Most of my projects start the same way. Something on my own computer bothers me, so I measure it and fix it.

### Featured projects

| Project | What it does | Stack |
|---|---|---|
| [**rogctl**](https://github.com/muhammedaliaka/ROGCTL) | Thermal and power controller for ASUS ROG laptops. Classifies the workload, rewrites the fan curve, caps the GPU clock and limits FPS. A measured replacement for Armoury Crate's manual mode. | Rust, ACPI, NVML, NVAPI |
| [**Hardware Tester**](https://github.com/muhammedaliaka/donanim-kontrol) | Portable, offline kit for buying and selling used computers. Runs from a USB stick, stress-tests the machine and produces a neutral report with a sourced price band. | PowerShell, WMI, HTML |
